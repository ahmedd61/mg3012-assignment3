# GoalVault dApp: Truffle + Ganache (MG3012 Assignment 3)

This project extends Assignment 2. The same **GoalVault** savings-vault contract is now compiled,
deployed and tested with the **Truffle Suite** on a local **Ganache** blockchain, instead of Remix and Sepolia.
You set a goal in ETH, deposit toward it, and can only withdraw once your savings reach the goal.

## What changed from Assignment 2
| | Assignment 2 | Assignment 3 |
|---|---|---|
| Tooling | Remix IDE | Truffle (compile, migrate, test) |
| Network | Sepolia testnet | Local Ganache (`127.0.0.1:7545`, chain ID 1337) |
| Deployment | Manual, paste address by hand | `truffle migrate` writes the address into the frontend automatically |
| Testing | Manual clicks | Automated `truffle test` suite (9 tests) |
| Frontend | One `index.html` | `index.html` + `script.js` + `style.css`, plus an on-chain **activity log** |

The contract itself (`contracts/SmartContract.sol`) is unchanged.

## Contract functions
| Function | Type | Purpose |
|---|---|---|
| `setGoal(goalWei)` | write | Set or change your savings goal |
| `deposit()` | write (payable) | Add ETH to your vault (goal must be set) |
| `withdraw()` | write | Withdraw everything once balance >= goal |
| `getVault(user)` | read | Balance, goal, and whether you can withdraw |
| `totalLocked()` | read | Total ETH held by the contract |

Events: `GoalSet`, `Deposited`, `Withdrawn` (used by the activity log in the frontend).

## Prerequisites
- [Node.js](https://nodejs.org) (LTS) and npm
- [Git](https://git-scm.com)
- MetaMask browser extension
- Truffle and Ganache (command-line version):
  ```
  npm install -g truffle ganache
  ```
  Check with `truffle version` and `ganache --version`.

> On Windows PowerShell, if `npm` is blocked by "running scripts is disabled", run
> `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned` once.

## Setup and commands

**1. Start the local blockchain** (keep this window open):
```
ganache --port 7545
```
It prints 10 funded test accounts and their private keys, and `RPC Listening on 127.0.0.1:7545`.

**2. In a second terminal, from the project folder, compile:**
```
truffle compile
```

**3. Deploy to Ganache:**
```
truffle migrate
```
This deploys `GoalVault`, prints the contract address and writes it to `frontend/contract-config.js`.
To redeploy from scratch (for example after restarting Ganache) use `truffle migrate --reset`.

**4. Run the automated tests:**
```
truffle test
```
The 9 tests cover: setting goals, rejecting a zero goal, rejecting deposits without a goal or without ETH,
tracking balances and `totalLocked`, blocking early withdrawal, allowing withdrawal at the goal
(and resetting the vault), and keeping each user's vault separate.

**5. Connect MetaMask to Ganache** (one-time):
1. In MetaMask, add a network: Network name `Ganache Local`, RPC URL `http://127.0.0.1:7545`,
   Chain ID `1337`, currency symbol `ETH`. (The dApp also offers to add it for you on Connect.)
2. In MetaMask choose **Import account** and paste one of the private keys printed by Ganache.
   These are fake test keys that only work on your local chain.

**6. Serve and open the frontend** (MetaMask does not work from a `file://` page):
```
npx http-server frontend -p 8080
```
Open `http://127.0.0.1:8080`, click **Connect MetaMask**, then try:
1. Set goal, for example `1` ETH
2. Deposit `0.5` ETH, then `0.5` ETH
3. Watch the progress bar and activity log update
4. **Withdraw all** once the goal is reached (before that it is rejected by the contract)

## Troubleshooting
- **`truffle compile` cannot download the compiler:** you need an internet connection the first time
  (Truffle downloads solc 0.8.20). Try again, or check your network/VPN.
- **MetaMask says "nonce too high" or transactions hang after restarting Ganache:** in MetaMask open
  Settings > Advanced > **Clear activity tab data** for the Ganache account, then retry.
- **dApp says "No contract found":** Ganache was restarted. Run `truffle migrate --reset` and reload the page.
- **dApp says "No contract address yet":** run `truffle migrate` first.
